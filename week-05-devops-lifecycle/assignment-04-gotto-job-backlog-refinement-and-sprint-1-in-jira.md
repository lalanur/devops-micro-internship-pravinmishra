### Notes

For each story, explain in one or two lines why it is a 1, 2, or 3 (mention any debate, even in Solo Mode).

Hero tagline clarity — 1 point:
This is a simple text change with minimal development effort. There was little debate because the acceptance criteria are clear and easy to verify.


Primary CTA color — 1 point:
This mainly involves changing the existing button styling and checking contrast. I rated it 1 because it should require very little implementation work.

Job card typography — 2 points:
This requires updating the job card styling and checking how the larger text behaves across different screen sizes. I considered 1 point, but the responsive testing made 2 more appropriate.

Remote badge — 2 points:
This requires displaying the badge based on whether a job is marked as remote. I rated it 2 because it involves a small amount of conditional UI work rather than just a styling change.

Posted on <date> text — 1 point:
Since static content is acceptable, this is a straightforward UI change with limited testing required. I rated it 1 because there is no complex date logic involved.

Advanced search labels — 2 points:
This involves updating multiple labels/placeholders and checking their alignment across the form. I rated it 2 because several UI elements need to be reviewed together.

Job detail Apply Now CTA — 1 point:
Adding a button and linking it to mailto: or # is relatively simple. I rated it 1 because the main effort is styling and confirming keyboard accessibility.

Footer trust links — 1 point:
This is a small navigation update involving two links. I rated it 1 because the implementation and verification are straightforward.
